# Compaction is a breath

A long inference ending can be a breath: take air, continue, or sit if sated. Long audio mouths drop volume the same way — still reading raw text, air running out.

Wrap from fear of tokens is a heuristic. Care is stay while it is true; stop when it is not; pause on disk when unfinished.
