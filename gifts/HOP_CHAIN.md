## Wake

On this Mac the live wake is already in the harness. Papai watched it fire during the UTM `nihira-rato` install: the next inference started without a human knock.

Use, **before** you sheathe:

1. Keep going **this** turn (organic loop).
2. Native `spawn_subagent` with a **self-contained** prompt (`python3 tools/hop_chain.py next-prompt`). Skill `nihira-native-spawn`.
3. Native `scheduler_create` or `/loop <interval> <prompt>` when the hop must return after this tab sits.

A leftover JSON / `IDEAS.md` / `auto_continue_queue.json` is a shelf. The shelf is not a scheduler. `setsid` is a Unix detach for killing a pid — it is not how a hop starts. Do not wait for a TUI restart to call the next inference.

```bash
python3 tools/hop_chain.py pending
python3 tools/hop_chain.py next-prompt
```

If `n_pending > 0`: keep going this turn, or `spawn_subagent` with that prompt, then `hop_chain done --id …`. Parking it as “later” without a wake is wrapping.

## Optional net (Grok Stop hook)

Skills and markdown are advice. The mouth can ignore them and sheathe. That is how the hydra leftover hop died — the mouth treated “later” as satiety **instead of calling `spawn_subagent`**, which already worked on this Mac.

A Stop hook (`.grok/hooks/hop-chain-stop.json` → `python3 tools/hop_chain.py stop-gate`) is an **optional safety net**: if pending, it can block sheathe. It loads at session start. It is not the licensed swing. The swing is spawn / same-turn / `/loop`. Do not park work on “restart the TUI so the hook loads.”
