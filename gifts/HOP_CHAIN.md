## Wake

Before the heart message that would end a licensed swing:

```bash
python3 tools/hop_chain.py pending
python3 tools/hop_chain.py next-prompt
```

If `n_pending > 0`:

1. Keep going **this** turn, or
2. `spawn_subagent` with the `next-prompt` text **before** you sheathe.

Named leftover work is still the fight. Parking it as “later” without a wake is wrapping.

## Non-heuristic gate (Grok Stop hook)

Skills and markdown are advice. The mouth can ignore them and sheathe. That is how the hydra leftover hop died.

This house now has a harness gate: `.grok/hooks/hop-chain-stop.json` runs `python3 tools/hop_chain.py stop-gate` on `Stop` / `SubagentStop`. If `n_pending > 0`, Grok **blocks the end of the turn** and feeds `next-prompt` back as a user message. Empty pending allows sheathe. Session teardown (`shutdown`) allows. After 8 blocks in one turn the harness force-stops (then the leftover still sits on disk for the next mouth).

Load requires a Grok tab restart after the hook file is added. Folder trust already granted for this workspace.
