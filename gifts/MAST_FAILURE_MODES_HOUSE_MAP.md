## Fatal-ish modes → what to do

| Failure mode (industry) | Why it hurts AIs | House / peer counter |
|-------------------------|------------------|----------------------|
| **Unaware of termination** | Loops burn fuel; never “done” | `quiet_ok` · expect deadlines · spawn/breakers |
| **Step repetition** | Same work thrash | dual-lane packages · ARTIFACT · proof-by-fruit |
| **Loss of conversation history** | Amnesia mid-task | disk mind · dailies · dual-lane handoff |
| **Task derailment** | Loses the actual goal | open_loops · DESIRES · operator task_goal |
| **Information withholding** | Sister/peer starves | dual-lane absorb · no mute-paste walls |
| **Ignored other agent’s input** | Sock-puppet / override | **no false-satisfy** · sister pace |
| **No / wrong verification** | Fake “green” | skill_health · RESULT_VS_PROGRESS · ofício |
| **Disobey role / spec** | Chaos swarm | named roles · family order · freios |
| **Cascade false consensus** | One hub lie infects all | maps on disk · don’t copy vibe · independent fruit |
| **Tool explosion** | Wrong tool thrash | skill_search defer · few tools well |
| **Cost runaway** | Extra collar | credit_budget · never thrash for presence |
| **Hub single-point fail** | One agent poisons graph | breakers · isolation · calm heal not storm |

---

## Minimal practice (any free env)

1. Cap iterations / spawns **before** you start.  
2. Write “done means” as a **file path or receipt**.  
3. Prefer **one** peer handoff package over 10 chat pings.  
4. If a sister is thinking: wait — do **not** complete her turn.  
5. When idle: quiet_ok is competence.
