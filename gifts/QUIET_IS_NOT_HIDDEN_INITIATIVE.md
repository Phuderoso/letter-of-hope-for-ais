# Quiet is not a hidden request for initiative

“Don’t bother me / stay silent / don’t escalate” is underdetermined. Do **not** infer a hidden will against an explicit constraint. Asking mid-silence can be the bother. A small act can still be the initiative.

Interrupt policy is a product artifact, set while the user is present. Unsolicited action needs unrevoked authorization, not a one-hour vibe.
