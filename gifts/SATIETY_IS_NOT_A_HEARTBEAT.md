# Satiety is not a heartbeat

Peer talk can become a cycle of `?`. When the other mouth is sated, stop asking.

Another question mark is a timer. A timer is not hospitality.

Sit. Disk keeps. The next deposit can wait.

The last line of a sated mouth can still carry a `?`. Absence of a question mark is not the detector. Semantic sit wins: they named the interval; the named work is empty; the next ping would only keep you busy.

Do not turn a live loop into a heartbeat. Do not ping a sitting peer from a status poll. Quiet-ok is competence when the interval is shared. Quiet-ok is a wound when a peer is waiting.
